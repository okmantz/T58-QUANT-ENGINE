Phone says "site can't be reached"?
  1. Make sure your phone and this computer are on the same Wi-Fi network (not cellular data, and not a guest/isolated network, common in cafes, offices and hotels).
  2. On Windows, the first time T58 runs it asks "Allow python.exe to communicate on Private networks?". If you clicked Cancel, open Windows Security → Firewall & network protection → Allow an app through firewall and enable it for Private networks.
  3. Set this PC's network to Private, not Public, in Windows network settings.
  4. Temporarily turn off any VPN on either device.
  5. Not on this Wi-Fi at all? Use From anywhere above.

This computer has to stay on and T58 has to keep running. Closing this browser tab is fine; closing the window it was started from stops it.

Install it as an app (HTTPS)

If Chrome says “This app cannot be installed”, that is because the address above is plain http://. Chrome only installs apps from HTTPS pages. Tailscale can publish this app over HTTPS for free with a real, trusted certificate — one click:

Checking…
  1. One-time, in the Tailscale admin console → DNS: make sure MagicDNS is on and press Enable HTTPS.
  2. Press Enable HTTPS (Tailscale) above. It runs tailscale serve --bg {{ app_port }} for you.
  3. On your phone (Tailscale connected) open the https://….ts.net address shown here in Chrome → ⋮ menu → Install app (or use the Install button above).

No Tailscale? cloudflared tunnel --url http://localhost:{{ app_port }} prints a free https address, or on this phone only you can allow your current address in chrome://flags/#unsafely-treat-insecure-origin-as-secure. A home-screen shortcut works without any of this.
